# Медиа в @frodgrambot — бесплатная версия

Render: Nurislombek's workspace, сервис gpt1, тариф Free. Нет платного worker,
диска или базы данных. Код публичный; токен и сессия — только в Environment.
Существующие проекты и webhook @frodgrambot не меняются.

## Использование

1. Открой страницу сервиса gpt1: это будит сервер после простоя.
2. Когда страница загрузится, нажми «Открыть бота» и отправь /media.
3. Пришли ссылку на сообщение или напиши `/media экономика` для поиска чата.
4. Выбери чат кнопкой, затем последние 10, 50 или 100 сообщений для поиска медиа.

/media_status — очередь, /media_cancel — отмена, /media_refresh — индекс чатов.
Доступ только владельцу. Команда в Telegram сама не будит эту версию сервера:
сначала нужно открыть страницу. Сохрани ссылку в Избранное Telegram.

## Однократное подключение

Останови старый telegram_media.py. Распакуй серверную папку рядом с ним:
prepare_server.py ищет папку private рядом с собой и на уровень выше.
Выполни `py -m pip install -r requirements.txt`, затем `py prepare_server.py`.
Введи API ID, API HASH и токен @frodgrambot локально. Если сессия не найдена,
потребуются телефон, код и пароль 2FA в терминале. Токен другого бота отклоняется.

Получится приватный .env. В Environment сервиса Render перенеси значения
TG_API_ID, TG_API_HASH, TG_BOT_TOKEN, TG_OWNER_ID и TG_USER_SESSION.
Остальные переменные уже настроены. Сохрани с новым деплоем, открой страницу
сервиса и проверь /media со ссылкой на небольшое вложение.
Не присылай .env или .session в чат и не загружай их в GitHub: они дают доступ
к аккаунту и боту. После настройки ноутбук можно выключать. Старый локальный
загрузчик оставь остановленным: не используй копию сессии одновременно с сервером.

## Ограничения Free

Render засыпает после 15 минут без web-запросов. Открытие страницы запускает его
снова, обычно примерно за минуту. Самопингов и искусственного удержания нет.
Индекс чатов, очередь и история отправок на временном диске теряются при сне,
перезапуске и деплое. Сессия восстанавливается из Environment, индекс строится
заново. Старые кнопки поиска могут устареть; прерванные запросы повтори.

Месячные часы, сборки и трафик ограничены; часть квот общая с другими Free
сервисами workspace. Неограниченное скачивание не гарантируется. Большая очередь
может прерваться при сне или перезапуске. Предел файла здесь 500 МБ;
Telegram также применяет свои лимиты. После отправки временные файлы удаляются.

Скачивается только то, что Telegram выдаёт аккаунту через API. Секретные чаты
и удалённые файлы не поддерживаются. Ссылка скачивает одно сообщение;
альбомы не объединяются. После перезапуска возможны повторные отправки.
Публичная страница не показывает списки чатов, файлы или секреты.

## Развёртывание и проверка

Python; build `pip install -r requirements.txt`; start `python web.py`;
тариф free, без диска. HTTP /healthz с needs_configuration означает, что
сервер развёрнут, но Telegram не подключён. starting_or_running означает,
что задача подключения запущена, и не доказывает успешную отправку медиа.
Реальную работу необходимо проверить в боте после подключения аккаунта.

На собственном VPS можно запустить `docker compose up -d --build`:
там том сохраняет данные; HTTP привязан к localhost.

Проверки: `python -m unittest -v test_server.py test_web.py`.
Для отзыва доступа останови сервис, удали секреты и заверши серверную сессию
в Telegram → Настройки → Устройства; токен можно отозвать в BotFather.
