# Медиа в твоём Telegram-боте

Настроено для **@frodgrambot**, размещение: **Nurislombek's workspace** в Render.
Токен другого бота будет отклонён. Исходный код и конфигурация подготовлены;
само наличие этого архива не означает, что сервис уже развёрнут или запущен.

Серверная версия дополнения к существующему боту. Работает от личной сессии
Telegram для чтения источников и от токена бота для отправки файлов владельцу.
Локальный скрипт telegram_media.py можно оставить как запасной вариант.

## Использование после подключения сервера

- Отправь `/media` своему боту.
- Пришли ссылку вроде `https://t.me/channel/123` или `https://t.me/c/123456/789`.
  Бот скачает вложение именно этого сообщения, если аккаунт имеет к нему доступ.
- Для поиска напиши `/media экономика` — появятся подходящие чаты с кнопками.
  После выбора чата выбери последние 10, 50 или 100 сообщений. Это количество
  проверяемых сообщений, а не гарантированное количество файлов.
- `/media_status` — последние задания и счётчики.
- `/media_cancel` — отменить очередь и текущую загрузку.
- `/media_refresh` — обновить список чатов в фоне. Первая индексация большого
  аккаунта может занять время; загруженные результаты уже доступны для поиска.

Другие аккаунты и команды из групп игнорируются. Команды `/start` и прежние
команды бота не перехватываются этим дополнением. Исходный код существующего
бота не изменяется; совместимость с его фактическими ответами надо проверить
при подключении. Альбомы не объединяются: ссылка скачивает одно сообщение.

## Однократный перенос входа с ноутбука

1. Останови старый скрипт через Ctrl+C.
2. Распакуй эту папку рядом с `telegram_media.py`, чтобы папка `private`
   старого скрипта находилась на один уровень выше этой папки. Либо положи
   `prepare_server.py` рядом со старой папкой `private`.
3. Выполни `py -m pip install -r requirements.txt`, затем `py prepare_server.py`.
4. Введи API ID, API HASH и токен того же бота. Если существующая сессия найдена,
   повторный вход не нужен. Иначе код и пароль вводятся локально в терминале.
5. Получится приватный файл `.env`. Не присылай его в чат, не загружай в GitHub
   и не включай в публичные архивы: он содержит доступ к твоему аккаунту и боту.

## Размещение на собственном VPS с Docker

Скопируй серверную папку и приватный `.env` на свой сервер по защищённому
соединению. В этой папке выполни:

```sh
docker compose up -d --build
docker compose logs --tail 30
```

После запуска напиши боту `/media`. Ноутбук можно выключить. Запускается
ровно один экземпляр. Том `media-data` хранит сессии, индекс, очередь и историю
отправок. Не удаляй том при обновлении; `docker compose down -v` удалит данные.

## Размещение на Render

Файл `render.yaml` описывает один постоянно работающий Background Worker с
диском 3 ГБ. Это платные ресурсы. До Apply проверь итоговую стоимость в Render;
трафик при загрузке и повторной отправке крупных файлов тоже расходуется.
Бесплатный web-сервис Render засыпает и не подходит для этой версии.

Код без секретов должен находиться в отдельном Git-репозитории. После подключения
Blueprint перенеси пять значений TG_* из локального `.env` в приватные переменные
Environment. DATA_DIR и MAX_FILE_MB уже указаны в Blueprint. Deploy создаёт
новую сессию бота на сервере; старый локальный загрузчик оставь остановленным.

После деплоя проверь логи на `Media companion ready`, отправь `/media` и ссылку
на небольшой файл, проверь `/media_status` и отмену задания. Автоматические
тесты не заменяют эту проверку с реальным Telegram-аккаунтом.

## Ограничения

Скачивается лишь то, что Telegram выдаёт подключённому аккаунту через API.
Секретные чаты и удалённые вложения не поддерживаются. Верхний предел временного
файла по умолчанию 1900 МБ; Telegram может отклонить загрузку по своим лимитам.
Файлы передаются по одному и временно занимают место на диске сервера, после
отправки или ошибки удаляются. Сжатие и альбомы в исходном виде не гарантируются.

Очередь переживает перезапуск, завершённые отправки не повторяются. При аварии
точно между отправкой в Telegram и записью результата в базу возможен дубль.
Отмена не удаляет уже присланные сообщения. Изменённое вложение с прежним ID
тоже считается уже отправленным. Для повторного скачивания потребуется отдельно
сбросить запись, обычная кнопка этого не делает.

Для отзыва доступа заверши сессию в Telegram → Настройки → Устройства, останови
сервер и удали его секреты. Токен бота при необходимости отзывается в BotFather.
